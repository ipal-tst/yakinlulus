Jika \( f(x) = 2x^2 - 3x + 5 \), berapakah nilai dari turunan pertama \( f'(2) \)?

close
Jawaban Kamu B. 3
check
Jawaban Benar D. 5

Langkah pertama adalah mencari fungsi turunan pertama \( f'(x) \):

f(x) = 2x² - 3x + 5
f'(x) = 2(2x) - 3(1) + 0
f'(x) = 4x - 3

Kemudian substitusikan nilai \( x = 2 \):

f'(2) = 4(2) - 3
f'(2) = 8 - 3
f'(2) = 5

Jadi, jawaban yang benar adalah D.
