# 4. Persona 1 - Student

## 4.1 Persona Overview

| Attribute | Description |
|-|-|
| Persona Name | Student |
| Role | Learner / Exam Participant |
| Priority | Primary User |
| MVP Availability | Yes |

---

# 4.2 Profile

Student adalah pengguna utama yang menggunakan YakinLulus.id untuk:

- belajar materi
- latihan soal
- mengikuti simulasi ujian
- mengetahui perkembangan kemampuan

Target pengguna:

```

SD Kelas 4-6

*

SMP Kelas 7-9

*

SMA/SMK Kelas 10-12

*

Gap Year / UTBK Preparation

```

---

# 4.3 Student Goals

## Academic Goal

Siswa ingin:

- meningkatkan nilai akademik
- memahami materi pelajaran
- lulus ujian dengan hasil terbaik
- mempersiapkan ujian masuk perguruan tinggi


---

## Learning Goal

Siswa ingin:

- mengetahui materi yang belum dikuasai
- mendapatkan latihan yang sesuai kemampuan
- belajar dengan cara yang mudah dipahami


---

# 4.4 Student Pain Points

## Pain Point 1

### Sulit menemukan latihan soal berkualitas

Kondisi:

```

Banyak sumber soal

↓

Tidak tahu mana yang sesuai

```

Kebutuhan:

- bank soal terstruktur
- filter berdasarkan kebutuhan


---

## Pain Point 2

### Tidak mengetahui kelemahan belajar

Kondisi:

```

Nilai rendah

↓

Tidak tahu penyebabnya

```

Kebutuhan:

- analisis hasil
- rekomendasi materi


---

## Pain Point 3

### Kurang pengalaman ujian digital

Kondisi:

```

Latihan biasa

≠

Kondisi ujian sebenarnya

```

Kebutuhan:

- CBT simulation
- timer
- exam experience


---

# 4.5 Student Behavior

Karakteristik:

- menggunakan smartphone sebagai perangkat utama
- membutuhkan hasil cepat
- menyukai visualisasi progress
- membutuhkan motivasi belajar


---

# 4.6 Student Product Expectation

Student berharap:

```

Login

↓

Pilih pelajaran

↓

Latihan soal

↓

Dapat nilai

↓

Tahu kelemahan

↓

Menjadi lebih baik

```

# 5.4 Teacher Pain Points

## Pain Point 1

### Pembuatan soal membutuhkan waktu lama

Saat ini:

```

Cari referensi

↓

Buat soal

↓

Format dokumen

↓

Distribusi

↓

Koreksi

```

Masalah:

- banyak pekerjaan manual
- sulit dikelola


---

## Pain Point 2

### Sulit menganalisa kelemahan siswa

Guru biasanya hanya melihat:

```

Nilai akhir

```

Tetapi membutuhkan:

```

Materi lemah

*

Pola kesalahan

*

Progress

```

---

# 5.5 Teacher Product Expectation

Guru membutuhkan:

- question management
- exam builder
