# 30. QA Checklist

□ Logo lengkap.

□ Favicon lengkap.

□ SVG bersih.

□ Tidak ada asset duplikat.

□ Semua icon konsisten.

□ Gambar terkompresi.

□ WebP/AVIF tersedia.

□ Alt Text tersedia.

□ Lisensi aman.

□ Struktur folder sesuai.

□ Naming Convention sesuai.

□ Asset siap untuk CDN.

# 31. Best Practices

Gunakan:

✔ SVG untuk icon

✔ WebP/AVIF untuk gambar

✔ Lottie untuk animasi ringan

✔ Inter sebagai font utama

✔ Lucide sebagai icon system

✔ Storyset sebagai ilustrasi utama

✔ CDN untuk asset statis

✔ Lazy Loading

✔ Responsive Image

Hindari:

✖ PNG untuk icon

✖ JPEG untuk ilustrasi

✖ Asset >1 MB

✖ Stock photo dengan watermark

✖ Font terlalu banyak

✖ Icon dengan gaya berbeda

✖ Hardcoded asset path
