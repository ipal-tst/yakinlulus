# Domain Purpose

AI Domain bertanggung jawab mengelola seluruh layanan Artificial Intelligence pada platform YakinLulus.

Domain ini menyediakan layanan lintas domain seperti generative AI, semantic search, embedding, klasifikasi, rekomendasi, OCR, speech processing, dan evaluasi kualitas konten.

AI Domain tidak memiliki data akademik maupun data bisnis utama.
