# 1. Overview

AI Module merupakan domain yang menyediakan seluruh kapabilitas Artificial Intelligence pada platform YakinLulus.id. Modul ini dibangun sebagai **AI Orchestration Layer**, sehingga seluruh fitur AI menggunakan satu pintu layanan yang konsisten, aman, dan mudah dikembangkan.

AI Module tidak bergantung pada satu model tertentu. Seluruh Large Language Model (LLM), embedding model, OCR engine, speech model, maupun computer vision diakses melalui abstraction layer sehingga dapat diganti sesuai kebutuhan.

Pada MVP, AI difokuskan untuk mendukung:

* Question Generation
* Question Improvement
* Question Validation
* Material Generation
* Material Improvement
* AI Explanation
* AI Recommendation
* AI Tutor
* Semantic Search
* OCR Import

Roadmap berikutnya mencakup adaptive learning, AI tutor multimodal, proctoring, hingga learning agent.

# 39. Summary

AI Module merupakan lapisan orkestrasi kecerdasan buatan pada YakinLulus.id yang menyediakan layanan AI secara terpusat untuk seluruh domain aplikasi. Dengan arsitektur berbasis abstraction layer, event-driven processing, prompt management, model routing, RAG, serta dukungan PostgreSQL + pgvector untuk semantic search, modul ini memungkinkan pengembangan fitur AI yang fleksibel, skalabel, dan tidak bergantung pada satu penyedia model tertentu. Modul ini menjadi fondasi utama untuk otomatisasi pembuatan soal, materi pembelajaran, rekomendasi belajar, serta evolusi platform menuju adaptive learning berbasis AI.
