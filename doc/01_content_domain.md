# Content Domain Charter

Version : 1.0

Status : Draft

Type : Conceptual Domain

---

# 1. Purpose

Content Domain merupakan domain konseptual yang mendefinisikan standar seluruh jenis konten pada platform YakinLulus.

Domain ini bukan Domain implementasi.

Domain ini tidak memiliki tabel database.

Domain ini tidak memiliki API.

Domain ini berfungsi sebagai pedoman desain bagi seluruh Content Domain.

---

# 2. Objective

Menyatukan seluruh jenis konten.

Mengurangi duplikasi desain.

Mempermudah ekspansi jenis konten baru.

Menjadi standar metadata konten.

Menjadi fondasi AI, Search, RAG, dan Recommendation Engine.

# 9. Business Rules

Content wajib memiliki Owner.

Content wajib memiliki Status.

Content wajib memiliki Version.

Content wajib dapat diaudit.

Content dapat memiliki lebih dari satu Tag.

Content dapat memiliki banyak Media.

Content tidak boleh dihapus secara fisik apabila telah digunakan oleh Domain lain.

---

# 10. Non Goals

Content Domain tidak menyimpan data bisnis.

Content Domain tidak memiliki tabel database.

Content Domain tidak memiliki service.

Content Domain tidak mengelola Question.

Content Domain tidak mengelola Learning Resource.

Semua implementasi dilakukan oleh Domain masing-masing.
